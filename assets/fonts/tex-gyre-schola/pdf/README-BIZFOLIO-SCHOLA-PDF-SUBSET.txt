BizFolio Schola PDF Subset (WOFF2): a MODIFIED version of TeX Gyre Schola, not the original font.

Derived from: TeX Gyre Schola by the GUST e-foundry (the unmodified originals are in the parent folder,
with their checksums in README-TEX-GYRE-SCHOLA.txt).
Licence: GUST Font License / LaTeX Project Public License 1.3c (see ../GUST-FONT-LICENSE.txt).

Changes: character subset only (Latin, Latin-1, Latin Extended-A/B/Additional, combining accents,
punctuation, currency, a few symbols),
hinting removed, converted to WOFF2, and the font names changed to "BizFolio Schola PDF Subset" as the
licence requests for modified versions. Glyph outlines are unchanged.

Built by scripts/fonts/subset-pdf-fonts.py. Used only by lib/pdf/pdf-fonts.ts (embedded in invoice and
credit-note PDF pages).

  bizfolio-schola-pdf-bold.woff2
  bizfolio-schola-pdf-italic.woff2
