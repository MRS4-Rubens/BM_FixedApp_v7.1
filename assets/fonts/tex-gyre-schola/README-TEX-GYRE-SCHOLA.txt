Used by lib/pdf/pdf-fonts.ts: embedded into the archival (PDF) HTML only, so finalized invoice
and credit-note PDFs render with the same Century-Schoolbook-style face on any renderer
(Cloudflare's browser has no Century Schoolbook). The app's screens are not affected.
